# LEGO Air Quality Monitor

An educational STEM kit developed by the Case Western Reserve University Institute for Smart, Secure and Connected Systems (ISSACS). Participants build a working model of an optical air quality sensor using LEGO bricks, custom electronics, and a Raspberry Pi Pico.

## What It Teaches

Real-world air quality monitors measure particulate matter (PM) by shining light through air and detecting how much is scattered by particles. This kit builds a physical model of that principle: a LEGO brick structure channels water vapor between a white LED and a photoreceptor. As vapor density changes, so does the light reaching the sensor — just as particles would affect a real PM sensor. An 8-LED bar graph displays the relative reading in real time.

## Repository Contents

- **`Models/`** — 3D-printable LEGO-compatible brick designs and PCB files
- **`docs/`** — Documentation for kit builders, instructors, and participants
- **`images/`** — Reference photos used in documentation
