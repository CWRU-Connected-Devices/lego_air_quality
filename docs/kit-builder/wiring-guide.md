# Wiring Guide

Pin assignments for the Raspberry Pi Pico.

| Pico Pin | Connected To       |
|----------|--------------------|
| VBUS     | Fan +5V            |
| VSYS     | Neopixel +5V       |
| GPIO 15  | White LED +5V      |
| GPIO 22  | Neopixel DIN       |
| GPIO 26  | Sensor data (ADC)  |
| 3V3      | Sensor +3.3V       |
| GND      | Neopixel GND       |
| GND      | White LED GND      |
| GND      | Fan GND            |
